# Симуляция мира

Учебная консольная симуляция на Java 21 и Maven. Кролики и овцы едят траву, волки атакуют травоядных. Животные двигаются случайно, голодают и размножаются; трава размножается, камни занимают клетки.

Если животное голодное и в одной из четырёх соседних клеток есть подходящая пища, оно пропускает движение и ждёт фазы питания. Сытое животное продолжает двигаться случайно.

## Запуск

Из корня проекта:

```sh
mvn compile
java -cp target/classes ru.boris.simulation.Main
```

В IntelliJ IDEA можно запустить метод `main` класса `ru.boris.simulation.Main`.
Настройки находятся в `src/main/resources/simulation.properties`: размеры мира, число ходов, начальные количества, характеристики видов и питание. После изменения настроек повтори `mvn compile`.

По умолчанию мир имеет размер 12×8, содержит 42 объекта и выполняет 50 ходов. `simulation.turn-count=0` выводит только начальное состояние. Для пустого мира установи все `initial-count` в 0. Начальное количество объектов не должно превышать площадь карты.

## Тесты

```sh
mvn test
```

Тесты проверяют движение, голод, питание, размножение, состояние животных и полный запуск, включая ноль ходов, пустой и заполненный мир.

## Статистика

Сначала сразу выводится `turn=0`, затем с паузой в одну секунду выполняется каждый следующий ход и выводится его статистика. Запуск на 50 ходов занимает примерно 50 секунд.

```text
turn=0 total=42 rabbit=6 sheep=4 wolf=2 grass=20 rock=10 starved=0 moved=0 attacks=0 born=0 grassEaten=0 killed=0
```

`total` и названия видов показывают текущее количество объектов. Остальные значения — события только завершённого хода:

- `moved` — сколько животных переместились, независимо от числа шагов;
- `attacks` — число ударов, включая несмертельные;
- `born` — число потомков животных и травы;
- `grassEaten` — сколько травы съедено;
- `killed` — сколько животных погибло от атак;
- `starved` — сколько животных погибло от голода.

Проверка баланса: `newTotal = oldTotal + born - grassEaten - killed - starved`.

Фазы идут в порядке: голод, движение, питание, размножение. Новый `TurnStatistics` создаётся на каждый ход и передаётся всем действиям. Количества видов считаются по карте. Размножение выполняется последним; потомки начинают действовать на следующем ходу. После вымирания животных симуляция продолжает выполнять оставшиеся ходы.
